# The original paper

`scutoid-paper.pdf` is the article that first described scutoids:

> Gómez-Gálvez, P. et al. "Scutoids are a geometrical solution to
> three-dimensional packing of epithelia." *Nature Communications* (2018).
> [doi:10.1038/s41467-018-05376-1](https://doi.org/10.1038/s41467-018-05376-1)
